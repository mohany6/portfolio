---

You are a senior Product Designer and Frontend Engineer. I need you to **redesign the UI/UX of two existing web applications** so they look modern, polished, and ready for the marketplace, while keeping all existing functionality intact.

For each project, follow this workflow:

## GLOBAL WORKFLOW (do this for both projects)

1. **Audit first.** Open the project, read the existing screens/components, note the current layout, colors, fonts, spacing, and every page/screen.
2. **Define a design system.** Create one consistent design language per project (see "Design Direction" below) and apply it to EVERY screen. Consistency is non-negotiable.
3. **Redesign screen by screen.** Rewrite templates/components. Do not leave any page with the old look. Update both desktop and responsive/mobile states.
4. **Do NOT change:** business logic, API contracts, routes/URLs, database schema, auth logic, backend behavior. This is a UI-only redesign.
5. **Deliver** a summary of what changed, a design-token table, and a checklist of every screen updated.

---

## DESIGN DIRECTION (shared baseline — customize per project)

Build everything on top of these principles so it feels like a real 2025 product:

- **Visual style:** Clean, airy, modern SaaS / marketplace aesthetic. Subtle shadows, generous whitespace, rounded corners (8–16px), 1px borders with low-opacity color, soft gradient accents. Light theme by default with a polished dark-mode-ready palette.
- **Typography:** Use system font stack or Inter (self-host or CDN). Clear hierarchy: large bold headings, medium body text (14–16px), readable line-height (1.5–1.6).
- **Color system (tokens):** Define CSS custom properties / Tailwind theme extension / SCSS variables with: `--primary`, `--primary-hover`, `--surface`, `--surface-muted`, `--border`, `--text`, `--text-muted`, `--success`, `--warning`, `--danger`, `--bg`. Use one primary + one accent color per project.
- **Components:** Rebuild these as reusable components everywhere they appear: buttons (primary/secondary/ghost/danger, with hover + active + disabled + focus-visible states), form inputs (with floating or clear labels, error states), cards, badges, avatars, tables (with sticky header, hover rows, empty state), modals, toast/notification, empty states (icon + title + description + CTA), skeleton loading, page headers (title + subtitle + actions), and pagination.
- **Navigation:** Sticky top navbar with logo, nav links, active state, user menu. Sidebar for admin/vendor dashboards.
- **Polish details:** Focus rings (`focus-visible`), smooth transitions (150–200ms), hover lift on cards, micro-animations, meaningful icons (inline SVG or a light icon lib), accessible contrast (WCAG AA), proper `aria` labels, and semantic HTML.
- **Empty & loading states everywhere** — never show a raw blank page or "loading…" text.
